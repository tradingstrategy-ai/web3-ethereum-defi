# Axis Origin vault research

## Identification

- **Chain:** Ethereum mainnet (chain ID 1)
- **Vault address:** [`0xAD958C4c0c90bf0216e0f5472F074a9AB30f595F`](https://etherscan.io/address/0xAD958C4c0c90bf0216e0f5472F074a9AB30f595F)
- **Protocol product:** Axis Origin Vault
- **Infrastructure protocol:** Upshift, built on August smart-contract infrastructure
- **Axis product page:** [Axis Origin Vault](https://app.axis.to/origin)
- **Upshift vault record:** [Upshift API entry](https://api.upshift.finance/v1/tokenized_vaults/0xAD958C4c0c90bf0216e0f5472F074a9AB30f595F)
- **Documentation:** [Upshift multi-asset vault architecture](https://docs.upshift.finance/vault-architecture/multi-asset-vaults)
- **DefiLlama:** No matching adapter or protocol page found during this investigation.

Axis markets Origin as a public pre-deposit phase for its USDx strategy. The
Upshift API identifies the deployment as the active, visible `multiAssetVault`
with public type `Pre-deposit` and name `Axis Origin USDx`. Axis is the listed
strategist; the vault is not an Origin Protocol / OUSD deployment despite the
similar product name.

## Contract architecture

The vault address is an EIP-1967 `TransparentUpgradeableProxy`. Its current
implementation is
[`0xeb5f80acea6060764e91c185be93752ab40f01c2`](https://etherscan.io/address/0xeb5f80acea6060764e91c185be93752ab40f01c2),
which is verified on Etherscan as `TokenizedVault`. The proxy was created via
the `MasterDeployer` factory at
`0x12629b4702901c2522e4f509ed20b3e85bffe2a6`; the creator address is labelled
`Deployer Wallet` in Upshift's public deployment backup.

The implementation is **not a standard ERC-4626 vault**. It instead accepts
multiple deposit assets through `deposit(address assetIn, uint256 amountIn,
address receiverAddr)` and issues a separate ERC-20 receipt token. The
Upshift documentation describes this model: users may deposit several approved
assets, while withdrawals settle into one reference asset.

## Ownership and source provenance

The public code search did not locate a public GitHub repository containing
the `TokenizedVault`, `OperableVault`, or `MasterDeployer` implementation.
However, Upshift's public [deployment backup repository](https://github.com/upshift-protocol/upshift-redis-backup)
registers this exact address as `axis-origin-usdx` and assigns it dedicated
vault and receipt-token subgraphs. The official Upshift documentation states
that its vaults use August smart-contract infrastructure. Therefore, the
evidence supports this attribution:

- **Axis** owns the user-facing Origin product and is named as its strategist.
- **Upshift/August** supplies the multi-asset vault, accounting, receipt-token
  and control framework.
- The verified Solidity source is available from Etherscan, but its upstream
  development repository was not publicly found. Do not treat the available
  public Upshift repositories as the complete Solidity source distribution.

## Fees and withdrawal terms

The current onchain values are:

- Management fee: `0` basis points.
- Performance fee: `0` basis points.
- Standard withdrawal fee: `0` basis points.
- Instant-redemption fee: `30` basis points.
- Withdrawal lag: `604800` seconds (7 days).

These values match the Axis application description of free queued redemption
after the 30-day term and an approximately 30-basis-point instant option. The
Upshift API additionally records a zero management-fee platform override and
an 18% displayed APY override; the latter is presentation metadata, not an
onchain fee setting.

## Security and audit notes

Upshift states that its contracts have been reviewed by Hacken, ChainSecurity,
Sigma Prime and Zellic in its [security overview](https://www.upshift.finance/blog/how-traditional-asset-managers-are-controlling-risk-in-defi).
This is platform-level evidence only: no audit report was found that explicitly
names this Axis deployment, its `TokenizedVault` implementation address, or
the Axis-specific configuration. The vault remains upgradeable, and its owner
and operator roles can change configuration, fees, limits and pause state
subject to the implementation's controls and timelocks.

## Tracking implication

Track this address as an **Upshift multi-asset vault / Axis Origin** product,
not as ERC-4626. Use its custom vault interface and the `ogUSDx` receipt token
for share accounting. Its reference asset is the Ethereum deployment of USDx,
which is distinct from the Plasma USDx token address.
