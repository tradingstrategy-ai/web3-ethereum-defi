Rysk API
========

Read-only Rysk Premium option-pool support with onchain lead discovery and
finalised epoch share-price equivalents through a dedicated
:class:`eth_defi.vault.base.VaultBase` adapter. Rysk is a DeFi protocol, not a
legally structured fund.
