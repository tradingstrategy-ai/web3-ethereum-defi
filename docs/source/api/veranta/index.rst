Veranta API
===========

This integration covers the unified avUSDC vault of Veranta, formerly known as Avantis.
It provides Base metadata and synchronous guarded
execution. See :doc:`the vault documentation </vaults/veranta/index>` for
supported deployment, fee rules, admission and execution evidence.
