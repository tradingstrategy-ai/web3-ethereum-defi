Symbiotic vaults
=================

`Symbiotic <https://symbiotic.fi/>`__ is shared collateral infrastructure for
onchain applications. Curators create vaults for one collateral asset and can
allocate capital to applications, economic-security arrangements, or selected
yield strategies. The project describes its Core V2 vaults as tokenised vaults
with a Universal Delegator that manages those allocations.

Vault deposits can be public or restricted by a curator-set allow-list and
limit. Management and performance fees are configurable per vault. A redemption
can depend on capital returning from the curator's selected adapters, so this
library does not advertise an immediate two-way deposit manager for Symbiotic
vaults.
