YieldBasis
==========

`YieldBasis <https://yieldbasis.com/>`__ provides leveraged liquidity-provider
shares (yb-LP/LT) for Curve Cryptoswap markets. The reviewed Ethereum products
in this dataset cover WBTC, cbBTC, tBTC and WETH, and are available through the
`Earn application <https://yieldbasis.com/earn>`__.

YieldBasis manages leveraged positions that retain BTC or ETH market exposure
while seeking trading-fee income. The underlying asset price, leverage,
liquidity, oracle behaviour and a temporary redemption discount can all affect
the value received on exit. The library's primary comparison uses a synthetic
USD accounting denomination, with separate native-asset performance retained
for context.

Generic ERC-4626 deposits, withdrawals and flow reconstruction are not
supported for these protocol-managed positions. For the Python adapter and
historical context storage, see the :ref:`YieldBasis API <yield-basis>`
documentation.
