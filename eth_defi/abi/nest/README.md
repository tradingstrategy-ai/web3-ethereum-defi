# Nest ABI sources

`NestVault.json` is a compact ABI for the verified `NestVault` implementation.
The implementation source and complete contract interfaces are published in
[plumenetwork/nest-protocol](https://github.com/plumenetwork/nest-protocol),
especially [`contracts/NestVaultCore.sol`](https://github.com/plumenetwork/nest-protocol/blob/main/contracts/NestVaultCore.sol).
The representative Avalanche nOPAL deployment is a transparent proxy at
[`0xd258029cf5a177e3306e09fbea63424543a505c0`](https://snowtrace.io/address/0xd258029cf5a177e3306e09fbea63424543a505c0#code),
whose verified implementation is `NestVault`.
