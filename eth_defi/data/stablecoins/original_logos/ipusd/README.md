# ipUSD logo sources

The token mark comes from the [official ipUSD website](https://ipusd.xyz/), which
also links to the [brand resources](https://ipusd.gitbook.io/ipusd-docs/resources).

- `ipusd.generic.svg`: [official pink SVG token mark](https://ipusd.xyz/brand/tokens/ipusd.svg),
  with a 48 × 48 view box and transparent corners. Downloaded on 2026-10-27.
- The website also supplies a purple mark for dark backgrounds; the pink mark
  is the selected source for this catalogue entry.

The repository's `scripts/logos/post-process-logo.py` converts the SVG into
`eth_defi/data/stablecoins/formatted_logos/ipusd/light.png`, a 256 × 256 PNG for
light backgrounds. The source colours and proportions are preserved.
