# limUSD logo

The token-specific brand mark comes from the [official Liminal brand kit](https://docs.liminal.money/more/brand-kit), downloaded on 2026-11-10.

- `limusd.generic.svg`: original vector asset.
- `limusd.generic.png`: original 620 × 620 RGBA raster asset.
- `../../formatted_logos/limusd/light.png`: 256 × 256 PNG produced from the original PNG with `scripts/logos/post-process-logo.py`. The PNG preserves sharper detail than the supplied SVG when rendered at this size.

Both originals depict the silver limUSD mark on a dark disc with transparent corners. No alternative colour variant was supplied for limUSD.
