# Tori trUSD logo

The token icon comes from Tori Finance's [official brand assets](https://docs.tori.finance/resources/brand).
The original [trUSD SVG](https://docs.tori.finance/logo/brand/trUSD.svg) was downloaded on 2026-10-28.

- Original: `trusd.svg`, SVG token mark, 977 bytes, 1024 × 1024 view box.
- Formatted: `../../formatted_logos/trusd/light.png`, 256 × 256 RGBA PNG.
- Processing: the SVG conversion and trimming/scaling helpers in
  `scripts/logos/post-process-logo.py`, preserving the official token mark and
  colours. Automatic dark-background recolouring is omitted because it inverts
  the circular token background and removes the pale symbol.
