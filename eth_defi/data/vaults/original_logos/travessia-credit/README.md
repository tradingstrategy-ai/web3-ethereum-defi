# Travessia Credit logo

Downloaded on 2026-11-09 from the [official website header](https://www.travessiacredit.com/):
[original WebP asset](https://www.travessiacredit.com/travessia_logo_dark.webp).
The header provides this brand mark; no brand kit or GitHub link is exposed there.
The original is a 323 × 165 RGBA WebP with transparency and a white/gold mark.
The corresponding [light-theme asset](https://www.travessiacredit.com/travessia_logo_light.webp)
is also downloaded and used for the light-background output.
The bright mark is suitable for a dark background.

Processed sequentially with the extract-vault-protocol-logo and post-process-logo
skills using `scripts/logos/post-process-logo.py`. The result is a transparent
256 × 256 PNG with the original proportions preserved. The dark-background output uses the white/gold mark; the generic and
light-background outputs use the dark/gold mark for legibility on white. No generated or redrawn logo is used.
