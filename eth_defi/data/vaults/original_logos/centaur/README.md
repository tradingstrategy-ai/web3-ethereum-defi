# Centaur logo

The curator supplied this brandmark with the Centaur onboarding request on
2026-10-26. The original attachment is preserved as `centaur.generic.jpg`
(318 × 318 pixels). The official project homepage is [Centaur](https://www.centaur.io/).

The formatted variants are 256 × 256 RGBA PNGs. The supplied light mark was
separated from its black JPEG background using a luminance matte after removing
the two-pixel outer JPEG frame, then trimmed
and scaled with `scripts/logos/post-process-logo.py`. This avoids background
removal artefacts and retains the original outline. `light.png` contains the
light mark for dark backgrounds; `dark.png` contains its colour-inverted mark
for light backgrounds. Both have transparent backgrounds.
