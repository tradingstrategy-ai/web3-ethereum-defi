# Defiable Asset Management logo sources

The logo assets were extracted from the public [Defiable Asset Management X
profile](https://x.com/Defiable_Crypto) and checked against the archived
[Defiable fund pages](https://web.archive.org/web/20240109072457id_/https://defiable.ca/defiable-large-cap-fund/).
The square `defiable-asset-management.brandmark.png` is used for the
standardised generic logo; the larger generic image is retained as the
original wordmark/source asset.
