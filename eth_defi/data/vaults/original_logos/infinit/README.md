# Infinit logo sources

Retrieved 2026-10-26 from the [official brand assets](https://docs.infinit.tech/others/brand-assets).
The official mark PNGs are 3000×1698. Originals are preserved verbatim.

- [Light mark](https://content.gitbook.com/content/0Miv104kfMA9xgOGe7S0/blobs/7S9SqrxbsPIYVI1vnU75/Logo%20Mark%20-%20White.png): `infinit.light.png`.
- [Dark mark](https://content.gitbook.com/content/0Miv104kfMA9xgOGe7S0/blobs/H3Uh5mqfC9PhAUWYDDyM/Logo%20Mark%20-%20Black.png): `infinit.dark.png`.

The generic logo processor misidentifies the surrounding rectangular source
background as part of the mark. Processed variants remove that background,
retain the official mark silhouette and centre it on a transparent 256×256 canvas.
`light.png` is light-coloured for dark backgrounds; `dark.png` is dark-coloured
for light backgrounds. No generated or reconstructed artwork is used.
