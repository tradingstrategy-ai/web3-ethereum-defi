# GMX logo sources

Logo assets for the GMX vault protocol.

## Sources

- Homepage: https://gmx.io/
- Official frontend repository: https://github.com/gmx-io/gmx-interface
- Rounded brand mark source: https://raw.githubusercontent.com/gmx-io/gmx-interface/master/src/img/ic_gmx_rounded.svg
- Wordmark source checked during extraction: https://raw.githubusercontent.com/gmx-io/gmx-interface/master/src/img/ic_gmx.svg

## Saved originals

- `gmx.generic.svg` - official rounded GMX brand mark from the frontend repository.
- `gmx.light.svg` - same rounded brand mark, used for dark website backgrounds because the icon includes its own dark circular field and bright GMX gradient mark.

The formatted outputs use the square rounded brand mark because the logo
post-processing workflow prefers brand marks over wordmarks for protocol icons.
