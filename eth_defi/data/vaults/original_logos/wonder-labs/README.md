# Wonder Labs logo sources

- **Archived official site**: <https://web.archive.org/web/20220901124743/https://wonderlabs.tech/>
- **Archived favicon / wordmark**: <https://web.archive.org/web/20220901124743id_/https://wonderlabs.tech/wl.ico>
- **Downloaded**: 2026-09-19

`wonder-labs.generic.ico` is the 256×144 transparent black Wonder Labs wordmark
served as the favicon by the archived official website. The current
`wonderlabs.tech` site has a different inline favicon and no downloadable brand
asset, so the archived asset is retained with its capture date and source.

The standard logo pipeline produced
`eth_defi/data/vaults/formatted_logos/wonder-labs/generic.png` as a 256×256
transparent PNG. The pipeline inverted the dark source mark to white for
visibility on dark backgrounds and preserved the original aspect ratio.
