# Bosera Asset Management International logo

The compact Bosera brandmark is the official favicon served by the
[Bosera International website](https://www.bosera.com.hk/en-US/):

- Source URL: `https://www.bosera.com.hk/en-US/favicon.ico`
- Retrieved: 2026-07-30
- Original format and dimensions: ICO, 32 × 32 pixels, RGBA
- Saved as: `bosera-asset-management-international.brandmark.ico`
- PNG extraction for processing: `bosera-asset-management-international.brandmark.png`

The favicon is the square red-and-black Chinese-character mark used by Bosera
and is therefore preferable to the existing horizontal header wordmark for
small-screen vault listings. The original header wordmark remains in this
folder as `bosera-asset-management-international.light.png` for provenance.
The official site exposes the brandmark only at favicon resolution; no public
brand-kit or larger icon-only vector was found.

The brandmark was processed with `scripts/logos/post-process-logo.py` into
256 × 256 transparent variants:

- `formatted_logos/bosera-asset-management-international/generic.png`
- `formatted_logos/bosera-asset-management-international/dark.png`
- `formatted_logos/bosera-asset-management-international/light.png`
