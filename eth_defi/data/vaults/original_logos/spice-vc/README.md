# SPiCE VC curator logo

- Source site: [SPiCE VC](https://spicevc.com/)
- Official assets: [`logo.png`](https://spicevc.com/img/logo.png) and [`logo-full.png`](https://spicevc.com/img/logo-full.png)
- Downloaded: 2026-07-30
- Original files: `spice-vc.logo.png` (official header lockup) and `spice-vc.logo-full.png` (official lockup with descriptor)
- Brandmark extraction: `spice-vc.brandmark.png` is the square SPiCE symbol cropped from the left side of the official `logo.png`; no text is retained.
- Dark-surface variant: `spice-vc.brandmark.light.png` is the same official symbol rendered in white with its source alpha channel preserved.

The previous source was a horizontal wordmark. The curator artwork now uses the compact SPiCE brandmark so it remains recognisable in a small square. The processed `generic.png` and `dark.png` retain the official purple (`#3d1061`); `light.png` is the white variant for dark surfaces.

Processed outputs were generated with [`scripts/logos/post-process-logo.py`](../../../../scripts/logos/post-process-logo.py), yielding transparent 256x256 PNGs in `eth_defi/data/vaults/formatted_logos/spice-vc/`.
