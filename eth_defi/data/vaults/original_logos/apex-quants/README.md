# Apex Quant Capital logo

Retrieved on 2026-10-26 from the [official website](https://www.apexquants.xyz/),
linked by the [Infinit APEX MultiStrategy vault](https://app.infinit.tech/vaults/apex-multistrategy).
The website declares its [SVG favicon](https://www.apexquants.xyz/favicon.svg)
as the brand icon. The header uses a text wordmark; no separate brand kit or
image logo was linked on the reviewed page.

`apex-quants.generic.svg` is the unmodified official vector icon: a white serif
A on a blue square, with a square 64 × 64 viewBox and an opaque background.
This is the Apex Quant Capital curator, distinct from the ApeX exchange.

The shared logo utility's SVG renderer produces 256 × 256 RGBA `light.png` and
`dark.png` under `formatted_logos/apex-quants/`. Both use the same official
colours. The blue tile is part of the original icon and is retained for both
themes; background removal and recolouring would change the brand asset.
