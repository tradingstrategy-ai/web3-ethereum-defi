# Flying Tulip original logo

`flying-tulip.generic.png` is the official Flying Tulip documentation icon,
downloaded on 2026-08-24 from
[`https://docs.flyingtulip.com/docs-icon.png`](https://docs.flyingtulip.com/docs-icon.png).

The icon is the square, purple Flying Tulip brand mark used by the official
[product documentation](https://docs.flyingtulip.com/product-suite/ft-usd/).
It was selected over third-party token listings and article graphics because it
is hosted on Flying Tulip's documentation domain and needs no crop from a
wordmark or marketing image.
