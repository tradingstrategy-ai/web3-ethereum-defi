# Derive logo source

`github-avatar.png` is the official [Derive GitHub organisation](https://github.com/derivexyz)
avatar, downloaded from `https://github.com/derivexyz.png?size=512` on
24 September 2026. It contains the orange Derive mark on a black roundel.
`docs-mark.png` is the transparent Derive mark from the
[official Derive documentation](https://docs.derive.xyz), downloaded from
`https://mintcdn.com/derive-a0490cef/Bt06Ji3mw21_R7pR/logo/derive.png` on
24 September 2026. `formatted_logos/derive/generic.png` uses the GitHub avatar;
`light.png` uses the transparent documentation mark for dark backgrounds. Both
are 256×256 outputs from `scripts/logos/post-process-logo.py`.
