# BNY Investments curator logo

- Source: [BNY Investments website](https://www.bny.com/investments/us/en/intermediary/about-us/)
- Official asset: `https://www.bny.com/content/dam/im/web/logos/bny_im_logo.svg`
- Retrieved: 2026-07-30
- `bny-investments.generic.svg` is the original official BNY Investments lock-up (wordmark).
- `bny-investments.brandmark.svg` is the compact teal arrow brandmark extracted from the official SVG. It is used for the favicon-like vault logo so the mark remains legible at small sizes.

The source artwork is an official transparent SVG. The brandmark was extracted without changing its geometry or colours, then processed with `scripts/logos/post-process-logo.py` into 256×256 transparent PNG variants.
