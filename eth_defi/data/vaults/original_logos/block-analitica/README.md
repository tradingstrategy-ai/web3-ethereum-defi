# Block Analitica logo

The existing `block-analitica.generic.svg` is the official website wordmark. For
the compact curator artwork, the brandmark was extracted from the official
Apple touch icon served by Block Analitica:

- Website: <https://blockanalitica.com>
- Source icon: <https://blockanalitica.com/apple-touch-icon.png>
- Retrieved: 2026-07-30
- Source dimensions: 180 × 180 px PNG (the `BA` monogram inside Block Analitica's
  open-square mark)

`block-analitica.brandmark.png` preserves the downloaded source. The
`*.light.png` and `*.dark.png` source variants are transparent conversions of
that same official mark for the two themes. The wordmark SVG is retained as
the original reference, but is not used for curator artwork.

The processed `generic.png` and `light.png` files use the white mark for dark
backgrounds; `dark.png` is the colour-inverted black mark for light
backgrounds. All processed files were generated with
`scripts/logos/post-process-logo.py` and are 256 × 256 transparent PNGs.
