# pToken logo

No official pToken logo is included.

The pToken issuer is currently not yet identified and has not published an
official website or brand asset. The two reviewed contracts contain product
labels supplied by their unlabelled deployer, but those labels cannot be used
as an official logo source.

``ptoken.light.svg`` is a local, neutral unknown-issuer fallback mark used only
to prevent a broken image in the dark frontend. It is not an official pToken
logo and must not be treated as evidence of authorship.
