# Buoy logo

Source: https://buoy.finance/favicon.svg, retrieved 2026-11-14.
The official square SVG is 628 × 628 and contains a dark brand mark on a solid
pale background. No separate official light/dark variants were found in the app.
For the transparent light variant, remove only the background rectangle and
recolour the existing vector paths white before running the repository's
post-processing script. The mark's geometry is unchanged. `light.png` is the
light-coloured variant for the website's dark backgrounds.
