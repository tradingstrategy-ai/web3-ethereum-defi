# Kamui logo sources

- Official website: <https://www.kamui.finance/>
- Official coloured brand mark: <https://www.kamui.finance/apple-touch-icon.png>
- Official light-theme favicon: <https://www.kamui.finance/favicon-light.png>
- Official dark-theme favicon: <https://www.kamui.finance/favicon-dark.png>
- Official wordmark: <https://www.kamui.finance/assets/kamui-logo.png>
- Downloaded: 2026-09-27

`kamui.generic.png` is the square 180×180 coloured Kamui brand mark used by
the official website as its Apple touch icon. `kamui.dark.png` and
`kamui.light.png` preserve the official 32×32 favicon variants, while
`kamui.wordmark.dark.png` retains the 318×60 horizontal wordmark. All assets
have transparent backgrounds.

The coloured brand mark is preferred for the standard square curator logo.

## Processed files

The transparent coloured mark was trimmed, centred and scaled to produce the
256×256 `generic.png` and `light.png` listing assets. Background removal was
not needed because the official source already contains an alpha channel.
