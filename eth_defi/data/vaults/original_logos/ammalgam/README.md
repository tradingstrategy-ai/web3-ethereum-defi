# Ammalgam curator logo sources

## Sources

- Homepage: https://ammalgam.xyz/
- Official brand kit, linked from the homepage: https://duelinggalois.notion.site/Ammalgam-Brand-Kit-19e3195c2bf580788c37f51bc6f98fa3?pvs=74
- Square brand mark: https://ammalgam.xyz/icon.svg
- Header wordmark: https://ammalgam.xyz/assets/logo.svg

## Files

- `ammalgam.generic.svg` — official square, coloured Ammalgam brand mark from
  the homepage favicon asset. It has a 16 × 16 viewBox and a transparent
  background.
- `ammalgam.wordmark.light.svg` — official white homepage header wordmark,
  including the coloured brand mark, with a 143 × 28 viewBox.

The square brand mark is the source selected for the standardised curator
logo, because it is an icon-only vector asset and remains legible at 256 × 256
pixels.
