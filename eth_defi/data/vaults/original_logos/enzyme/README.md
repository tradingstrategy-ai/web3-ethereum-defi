# Enzyme vault protocol logo sources

Logo sources for the Enzyme vault protocol metadata.

- `enzyme.brandmark.dark.svg` - black standalone Enzyme brand mark used by the
  mobile navigation on the official Enzyme homepage:
  https://enzyme.finance/
- `enzyme.brandmark.generic.png` - purple and white 256×256 brand mark used as
  the official Enzyme homepage favicon:
  https://cdn.prod.website-files.com/67c5ba4c41365a10f2c0d942/67c5ba4c41365a10f2c0d9c0_favicon-256x256.png
- `enzyme.wordmark.light.png` - archived white Enzyme wordmark for dark
  backgrounds, downloaded from the official Enzyme documentation:
  https://docs.enzyme.finance/onyx-protocol/contract-addresses
- `enzyme.wordmark.dark.png` - archived black Enzyme wordmark for light
  backgrounds, downloaded from the same official documentation page.

The official Enzyme X avatar uses the same standalone white brand mark on the
purple brand colour, independently confirming the current square identity:
https://x.com/enzymefinance

The formatted generic, light and dark logos use only the standalone brand
mark. The archived horizontal wordmarks are retained as source material, but
are not used for vault protocol listings.
