# Enzyme vault protocol logo sources

Logo sources for the Enzyme vault protocol metadata.

- `enzyme.light.png` - white Enzyme wordmark for dark backgrounds, downloaded
  from the official Enzyme documentation:
  https://docs.enzyme.finance/onyx-protocol/contract-addresses
- `enzyme.dark.png` - black Enzyme wordmark for light backgrounds, downloaded
  from the same official documentation page.

The source wordmarks are horizontal. The formatted logos centre the mark on a
transparent square canvas for use in the vault listing.
