# Monarq curator logo sources

## Official website

- Homepage: https://www.monarq-am.com/
- `monarq.website.wordmark.svg` — official stacked Monarq monogram and wordmark
  extracted from the site footer.
- `monarq.website.brandmark.svg` — official horizontal wordmark from the site
  navigation.

## Lagoon curator API

- API: https://app.lagoon.finance/api/curators
- `monarq.lagoon.png` — 159 × 159 PNG served by Lagoon's registered Monarq
  curator record at https://storage.googleapis.com/lagoon-logos/shares/monarq.

## Historical Upshift source

- `monarq.generic.svg` — Monarq monogram from the Upshift public vault API
  (`hardcoded_strategists[].strategist_logo`), retained for its original source
  provenance.
- Vault: https://app.upshift.finance/pools/14/0x2439D4bb753A0f3777d4C9011AFacc475ba6B951

The Lagoon square logo is used to generate the standardised 256 × 256
``light.png`` and ``dark.png`` variants. The legacy ``generic.png`` remains
available for existing Upshift curator metadata.
