# Apollo Crypto logo

- Source: [Apollo Crypto homepage](https://apollocrypto.com/)
- Official source asset: [`apollo-logo-1.svg`](https://apollocrypto.wpengine.com/wp-content/uploads/2022/11/apollo-logo-1.svg)
- Downloaded: 2026-07-30
- Saved original: `apollo-crypto.logomark.svg`

The official homepage logo asset is a transparent 318.5×87 lockup. Its left-hand
Apollo emblem is the compact brandmark used here; the adjacent “Apollo Crypto”
wordmark was intentionally excluded for small-screen curator artwork. The
brandmark SVG preserves the official charcoal A, blue gradient chevron, and centre
dot from that source asset.

The processed `generic.png`, `dark.png`, and `light.png` variants were generated
from `apollo-crypto.logomark.svg` with
[`post-process-logo.py`](../../../../../scripts/logos/post-process-logo.py).
