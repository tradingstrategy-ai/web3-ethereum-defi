# Fisher8 Capital logo sources

Official Fisher8 Capital logo assets were extracted from the Fisher8 Capital homepage
on 2026-07-30.

- Homepage: https://fisher8.capital
- Colour PNG logo (180x180): https://fisher8.capital/apple-touch-icon.png
- Monochrome SVG logo: https://fisher8.capital/safari-pinned-tab.svg

The source is the icon-only Fisher8 emblem (a brandmark), rather than a wordmark, so
it is suitable for the small favicon-like space used by curator logos.  The existing
`generic.png` and `light.png` files in the formatted-logo folder are 256x256
transparent PNGs generated from these official source assets with
`scripts/logos/post-process-logo.py`.

No replacement was necessary: the audit's wordmark classification was a false
positive for this curator.
