# Symbiotic logo sources

## Sources

- Homepage: https://symbiotic.fi/
- Official favicon / brandmark: https://symbiotic.fi/favicon.ico

## Notes

The official favicon is a 48×48 square brandmark. It is the only publicly
served standalone logo asset found after the linked brand-kit page returned a
404 response. The same colour brandmark is used for the generic, light, and
dark metadata variants because it remains legible on both themes.
