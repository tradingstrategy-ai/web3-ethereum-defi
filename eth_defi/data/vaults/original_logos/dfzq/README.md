# DFZQ logo source

- `dfzq.website.png` is the official DFZQ / Orient Securities International
  header logo downloaded from the DFZQ website. It is retained as the source
  reference and includes the organisation's wordmark.
- `dfzq.brandmark.svg` extracts the official red four-diamond brandmark from
  the vector logo previously supplied by the Asseto product API. This compact
  icon is used for vault metadata instead of the wordmark.
- `dfzq.generic.svg` is the original DFZQ / Orient Securities International
  partner logo displayed by the official Asseto product API.

Sources: <https://www.dfzq.com.hk/front/images/logo.png>,
<https://www.dfzq.com.hk/>, and
<https://static.asseto.finance/asseto/2026-04-29/di5didybcyuypabu83.svg>

Downloaded on 2026-07-30. The three 256x256 transparent variants in
`eth_defi/data/vaults/formatted_logos/dfzq/` were generated with
`scripts/logos/post-process-logo.py` from `dfzq.brandmark.svg`.
