# USYC logo assets

## Sources

- **Official USYC page**: <https://www.circle.com/usyc>
- **Official USYC SVG**: <https://cdn.prod.website-files.com/67116d0daddc92483c812e88/686eb4a62e20cbc02b9258df_usyc.svg>

The downloaded `usyc.svg` is Circle's official USYC combination logo (121×40).
`usyc-brandmark.svg` keeps the left 40×40 symbol only, removing the USYC
wordmark so it remains legible in the small curator-logo slot.

## Processing

The icon source was processed with `scripts/logos/post-process-logo.py` into
transparent 256×256 `generic.png`, `dark.png`, and `light.png` files. The
generic and dark variants retain the official USYC purple (`#29233B`); the
light variant is white for dark backgrounds.

Downloaded and processed: 2026-07-30.
