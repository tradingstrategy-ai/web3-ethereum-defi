# Rysk logo sources

- `rysk.light.png`: [official application favicon](https://app.rysk.finance/favicon-96x96.png), downloaded 2026-08-24.
- `rysk.dark.png`: [application dark-mode favicon URL](https://app.rysk.finance/favicon-96x96-dark-mode.png), downloaded 2026-08-24 for provenance.

Both URLs currently return the same byte-identical white Rysk mark. The
formatted `light.png` is suitable for dark backgrounds and `generic.png` is
the fallback. No `dark.png` is published because Rysk does not currently
provide a distinct dark-coloured mark for light backgrounds. Formatted variants
are generated with `scripts/logos/post-process-logo.py`.
