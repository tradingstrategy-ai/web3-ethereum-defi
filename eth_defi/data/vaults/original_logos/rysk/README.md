# Rysk logo sources

- `rysk.light.png`: [official application favicon](https://app.rysk.finance/favicon-96x96.png), downloaded 2026-08-24.
- `rysk.dark.png`: [official application dark-mode favicon](https://app.rysk.finance/favicon-96x96-dark-mode.png), downloaded 2026-08-24.

The light asset is the white Rysk mark for dark backgrounds; the dark asset is
the black mark for light backgrounds. Formatted variants are generated with
`scripts/logos/post-process-logo.py`.
