# M11 Credit logo sources

The previous source was a wide M11 Credit wordmark, which is difficult to read
in the small curator-list artwork. The official site also publishes a square
favicon containing the compact M11 monogram; that brandmark is the preferred
source for metadata.

- Website: <https://www.m11credit.com/>
- Official square favicon / brandmark (253 x 253 PNG):
  <https://www.m11credit.com/hubfs/11.png>
- Full SVG wordmark retained for provenance:
  <https://www.m11credit.com/hubfs/M11%20Credit/logos/m11-credit-logo.svg>

## Files

- `m11-credit.brandmark.png` — downloaded official favicon/brandmark (dark
  M11 monogram on transparency).
- `m11-credit.generic.svg` — previous full wordmark retained as an alternate
  source; it is no longer used for curator artwork.

## Processed output

The icon-only source was run through `scripts/logos/post-process-logo.py` to
produce transparent 256 x 256 PNGs under
`eth_defi/data/vaults/formatted_logos/m11-credit/`:

- `generic.png` and `light.png` — official light monogram generated by the
  post-processing pipeline for dark-background presentation.
- `dark.png` — RGB-inverted copy of the processed mark for light backgrounds,
  preserving the source alpha channel.
