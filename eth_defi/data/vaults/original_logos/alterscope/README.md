# Alterscope logo sources

## Source

Alterscope publishes the symbol-only brandmark in its official [brand assets
page](https://alterscope.org/brand-assets). The direct SVG downloads are:

- `alterscope.generic.svg` — [black Alterscope symbol](https://alterscope.org/brand/alterscope-symbol-black.svg), 1200 × 733 SVG.
- `alterscope.light.svg` — [white Alterscope symbol](https://alterscope.org/brand/alterscope-symbol-white.svg), 1200 × 733 SVG.

These are first-party brandmarks (without the Alterscope wordmark), taken from
`https://alterscope.org` on 2026-07-30.

## Processed results

The repository logo post-processing script produced 256 × 256 transparent PNGs
in `eth_defi/data/vaults/formatted_logos/alterscope/`:

- `light.png` — white symbol for dark backgrounds, processed from
  `alterscope.light.svg`.
- `dark.png` — black symbol for light backgrounds, colour-inverted from the
  processed white mark while preserving transparency.
- `generic.png` — standard generic output from `alterscope.generic.svg`.
