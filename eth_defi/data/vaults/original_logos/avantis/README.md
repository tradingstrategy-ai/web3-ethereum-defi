# Avantis logo provenance

The original 37×37 SVG brand mark is from the official SDK documentation before the Veranta rename:

https://raw.githubusercontent.com/Avantis-Labs/avantis_trader_sdk/fc8ae8aa3754d0bad47e90ae1a4c2b47c9fec6cc/docs/mintlify/favicon.svg

Retrieved 2026-11-04. The homepage returned HTTP 403; the pinned official repository provides a defensible original Avantis mark. Current SDK branding is Veranta, following the September 2026 rename. This integration retains the Avantis identity used by the avUSDC share token.

The SVG is square with transparent padding and a purple mark. Both variants use `scripts/logos/post-process-logo.py`: `dark.png` preserves the purple mark, and `light.png` uses a temporary SVG with the path fills changed to white for dark frontend backgrounds. Both PNGs are transparent 256×256 images; the originals remain unmodified.
