# Excellion Finance logo sources

The official [Excellion Finance homepage](https://excellion.finance/) exposes
the square brand mark at
[`/ef-logos/ef-favicon.png`](https://excellion.finance/ef-logos/ef-favicon.png)
and the horizontal word mark at
[`/ef-logos/ef-logo-horizontal.svg`](https://excellion.finance/ef-logos/ef-logo-horizontal.svg).

- `excellion-finance.generic.png` is the 64 × 64 transparent PNG brand mark
  downloaded from the official favicon asset.
- `excellion-finance.wordmark.svg` is the official 351 × 27 SVG word mark.

The square transparent brand mark is used to generate the formatted logo.
