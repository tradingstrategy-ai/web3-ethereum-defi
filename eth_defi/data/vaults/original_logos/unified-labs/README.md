# Unified Labs logo

## Source

- Official website: https://unifiedlabs.io/
- Official asset: https://unifiedlabs.io/logo.png
- Retrieved: 2026-07-30

The website publishes a transparent white Unified Labs combination logo. The
left-hand geometric symbol is the project's compact brandmark; the text on the
right is a wordmark. The brandmark was extracted from the official PNG (the
wordmark begins at approximately x=646) so that the vault icon remains legible
at small sizes. `unified-labs.generic.png` retains the complete official source,
while `unified-labs.brandmark.png` and `unified-labs.brandmark.dark.png` are the
brandmark source variants used for processing.

## Processing

`scripts/logos/post-process-logo.py` was run with the brandmark inputs to
produce 256×256 transparent PNGs in the formatted logo directory:

- `generic.png` and `light.png`: white brandmark for dark/transparent surfaces
- `dark.png`: black brandmark for light surfaces

The dark source was generated by replacing the official white mark's RGB values
with black while preserving its alpha channel and anti-aliased edges.
