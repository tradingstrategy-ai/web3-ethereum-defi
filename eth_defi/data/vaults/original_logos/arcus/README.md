# Arcus logo sources

The original logo variants were downloaded from the official [Arcus brand kit](https://arcus.xyz/brand-kit) on 2026-08-14.

- `arcus.generic.svg` — `https://framerusercontent.com/assets/V6L7yszoKvSfRLngFzGpqSjOsv4.zip`, `Arcus Logos/Image.svg`
- `arcus.light.png` — `https://framerusercontent.com/assets/V6L7yszoKvSfRLngFzGpqSjOsv4.zip`, `Arcus Logos/Image(Cream).png`
- `arcus.dark.png` — `https://framerusercontent.com/assets/V6L7yszoKvSfRLngFzGpqSjOsv4.zip`, `Arcus Logos/Image(Green).png`
- `arcus.generic.svg` was also served by the Arcus homepage at `https://framerusercontent.com/images/guf5M0HuNqEnFtbTOGRhtZGfWsU.svg?height=144&width=144`.

The formatted variants are 256×256 PNG files generated with `scripts/logos/post-process-logo.py`.
