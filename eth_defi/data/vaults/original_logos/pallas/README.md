# Pallas vault protocol logo source

`pallas.generic.svg` is the square brand mark served in the header of the
[official Pallas application](https://app.pallas.fund/).

`pallas.light.svg` preserves the official mark's geometry with a light brown
fill so it remains visible on dark backgrounds. It is a repository-derived
theme variant because Pallas does not publish a separate light logo.

- Source URL: https://app.pallas.fund/pallas_new.svg
- Downloaded: 2026-08-20
- Format: SVG, 1000 × 1000 viewbox

No official dark or light variant was available in the public application.
