# Zharta Finance logo sources

## Sources

- **Homepage**: https://www.zharta.io/
- **Brand mark**: https://cdn.prod.website-files.com/6734e8b50be7a2967fc4a262/6747260f9ca1fa676d4754d1_webclip.png
- **White wordmark**: https://cdn.prod.website-files.com/6734e8b50be7a2967fc4a262/67352a4ab354699646169f20_Zharta-logo-white.svg

## Files

- `zharta-finance.generic.png` — Official square 256×256 brand mark served as
  the Zharta website's Apple touch icon. The transparent mark has a purple to
  coral gradient.
- `zharta-finance.light.svg` — Official white wordmark served in the Zharta
  website header. It is retained as the light-background source variant but is
  not used for the square formatted curator logo.

## Notes

No separate brand kit or square dark wordmark was published on the official
site. The square official brand mark is the suitable source for the standard
formatted logo.
