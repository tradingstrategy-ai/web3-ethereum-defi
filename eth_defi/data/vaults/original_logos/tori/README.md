# Tori Finance logos

The originals were downloaded on 29 October 2026 from Tori Finance's
[official brand assets](https://docs.tori.finance/resources/brand).

- [Dark brand mark](https://docs.tori.finance/logo/brand/logo-dark-without-bg.svg): `tori.dark.svg`, 560 bytes, 655 × 428 view box, dark fill on transparency.
- [Light brand mark](https://docs.tori.finance/logo/brand/logo-light-without-bg.svg): `tori.light.svg`, 560 bytes, 655 × 428 view box, light fill on transparency.

The marks omit the wordmark and preserve the official geometry and colours.
The repository logo script's conversion and trimming helpers produced
`../../formatted_logos/tori/light.png` and `dark.png`, both 256 × 256 RGBA PNGs.
The light mark is intended for dark backgrounds and the dark mark for light
backgrounds. Protocol and curator metadata share these assets under `tori`;
the existing trUSD token icon remains separate.
