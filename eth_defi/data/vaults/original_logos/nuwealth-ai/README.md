# NuWealth.ai logo

The official [NuWealth.ai homepage](https://nuwealth.ai/) identifies this square
brand icon in its organisation metadata. It belongs to the Hyperliquid vault
operator, which is separate from NuWealth at nuwealth.io.

- Source asset: https://nuwealth.ai/assets/icon-512.png
- Retrieved: 2026-10-30
- Original: `nuwealth-ai.generic.png`, 512×512 RGBA PNG
- Formatted: `../../formatted_logos/nuwealth-ai/generic.png`, 256×256 PNG

Reproduce the formatted logo with the repository's standard processor:

```shell
INPUT_IMAGE=eth_defi/data/vaults/original_logos/nuwealth-ai/nuwealth-ai.generic.png OUTPUT_IMAGE=eth_defi/data/vaults/formatted_logos/nuwealth-ai/generic.png poetry run python scripts/logos/post-process-logo.py
```
