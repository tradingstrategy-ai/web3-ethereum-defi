# Rho Labs logo source

- Official media kit: <https://rho.trading/media-kit>
- Official generic logomark: <https://cdn.prod.website-files.com/6a3d0b251acd6da68ea24201/6a41113964e5cff40d1cdd7c_on-light.svg>
- Official light logomark: <https://cdn.prod.website-files.com/6a3d0b251acd6da68ea24201/6a41113921a2963f4051e856_on-accent.svg>
- Downloaded: 2026-08-21

The originals are square 200x200 SVG logomarks from Rho Labs' official media
kit. `rho-labs.generic.svg` is the indigo variant and `rho-labs.light.svg` is
the white variant. The standard logo pipeline produces transparent 256x256
PNGs in `formatted_logos/rho-labs/`.
