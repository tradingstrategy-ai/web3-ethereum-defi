# Mavrix Ventures logo

The logo was downloaded from the official [Mavrix Ventures website](https://mavrixventures.co/), whose header references this source image:

<https://img1.wsimg.com/isteam/ip/89343694-3a6f-4822-b136-221516dc581b/Mavrix%20Ventures%20Logo.png>

The source endpoint serves a 1500x1500 JPEG despite the `.png` filename. It is stored as `mavrix-ventures.generic.jpg` without conversion. The standardised 256x256 PNG is generated at `eth_defi/data/vaults/formatted_logos/mavrix-ventures/generic.png` using `scripts/logos/post-process-logo.py`.
