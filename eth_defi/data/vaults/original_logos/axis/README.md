# Axis logo sources

## Sources

- **Homepage:** https://www.axis.to/
- **Favicon:** https://www.axis.to/images/favicon.svg
- **Square brand mark:** https://www.axis.to/images/webclip.svg
- **Dark brand mark:** https://www.axis.to/images/Axis-Black.svg

All SVG assets are served directly from the official Axis homepage. No dedicated
brand kit or public GitHub repository was found.

## Files

- `axis.light.svg` — official 32 × 32 light brand mark on a dark square
  background, downloaded on 2026-07-29.
- `axis.generic.svg` — official 256 × 256 square brand mark, with a dark
  background and light Axis symbol. It is the source for the generic PNG.
- `axis.dark.svg` — official 60 × 61 dark Axis symbol on a transparent
  background, suitable as the source asset for light-background treatments.

## Formatted output

- `../../formatted_logos/axis/light.png` — standardised light-logo variant
  created from `axis.light.svg`.
- `../../formatted_logos/axis/dark.png` — standardised dark-logo variant
  created from `axis.dark.svg`.
- `../../formatted_logos/axis/generic.png` — 256 × 256 RGBA PNG generated
  from `axis.generic.svg` by `scripts/logos/post-process-logo.py`.
