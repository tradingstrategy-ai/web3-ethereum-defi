# Morpheus Trading Group logo sources

The original logo assets in this folder were obtained from official Morpheus
Trading Group properties:

- `morpheus-trading-group.dark.png` — the white Morpheus Trading Group
  wordmark served as the header logo on the [official Morpheus Trading Group
  website](https://www.morpheustrading.com/). Source asset:
  [Logo_MTG_002_all_white.png](https://kajabi-storefronts-production.kajabi-cdn.com/kajabi-storefronts-production/file-uploads/sites/2147797031/images/b8f7f71-066c-3677-af51-a2c36415133_Logo_MTG_002_all_white.png).
  PNG, 1000 × 193 pixels, transparent background.
- `morpheus-trading-group.generic.jpg` — the square brand avatar published by
  the [official `@mtg_crypto` X profile](https://x.com/mtg_crypto). Source
  asset:
  [profile avatar](https://pbs.twimg.com/profile_images/1622660661527433218/EK8dUPNT_400x400.jpg).
  JPEG, 400 × 400 pixels.

The X profile identifies itself as “MorpheusTrading.eth - Crypto Swing
Trading”, and the website header labels the wordmark “Morpheus Trading Group”.
Both assets are retained as downloaded; standardised PNG variants are created
by the post-processing workflow in the corresponding formatted-logo folder.
