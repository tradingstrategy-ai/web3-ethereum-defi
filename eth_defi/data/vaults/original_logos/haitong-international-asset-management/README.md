# Haitong International Asset Management logo

The compact brandmark in `haitong-international-asset-management.brandmark.png`
is the official Haitong International emblem used as the favicon on the manager's
website. It avoids the previous Guotai Haitong wordmark, which is retained in the
folder as provenance for the original metadata asset. The white brandmark source
is used for `light.png` on dark backgrounds.

Sources (accessed 2026-07-30):

- [Haitong International Asset Management website](https://gthtam.com.hk/asm/en-us)
- [Official favicon / brandmark](https://gthtam.com.hk/asm/assets/img/title_img.png)
- [Official header logo](https://gthtam.com.hk/asm/assets/img/logo.png)
- [Asseto-hosted partner logo](https://static.asseto.finance/asseto/2026-03-19/dh6viwd1w5vga7fyow.svg)
- [Haitong fund notice](https://gthtam.com.hk/hti_content/images/funds/Haitong_Global_RMB_Fixed_Income_Fund/Announcement/169/en-US/Haitong%20Global%20RMB%20Fixed%20Income%20Fund%20-%20Notice%20to%20Unitholders%20-%2020260129.pdf)

The favicon is a 65×62 transparent PNG. It was passed through
`scripts/logos/post-process-logo.py` to produce 256×256 transparent
`generic.png`, `dark.png`, and `light.png`. The generic/dark outputs preserve
the official Haitong blue (`#004b87`); the light output is white for dark UI
backgrounds.
