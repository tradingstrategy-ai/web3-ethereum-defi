# TruMarket logo sources

The original logo assets were downloaded from the official [TruMarket website](https://www.trumarket.tech/).

- `trumarket.generic.png` — footer logo asset: `https://www.trumarket.tech/trumarket-small-logo.png`; PNG, 1062×794 pixels, 190,551 bytes.
- `trumarket.wordmark.png` — header logo asset: `https://www.trumarket.tech/trumarket-logo-removebg-preview.png`; PNG, 577×433 pixels, 50,791 bytes.

Both assets were present in the official homepage HTML with `alt="TruMarket Logo"`. The higher-resolution generic asset was post-processed into `../../formatted_logos/trumarket/generic.png`.
