# Alchemix logo sources

- `alchemix.generic.png` is the 192×192 transparent application icon served
  by the official [Alchemix website](https://alchemix.fi/images/favicons/logo192.png).
- `alchemix.lagoon.svg` is the curator profile logo returned by the official
  [Lagoon curator API](https://cdn.lagoon.finance/curators/alchemix). It is
  retained as a vector reference for the specific Lagoon identity.

Both assets show the same Alchemix mark: a dark circular field with the
peach-coloured geometric emblem.
