# Altura logo sources

- **Project:** Altura
- **Official website:** https://www.altura.trade/
- **Source asset:** https://www.altura.trade/favicon.ico (retrieved 2026-07-30)
- **Source format:** 512×512 ICO/RGBA favicon containing Altura's turquoise stacked-arc brandmark on a black background.
- **Extraction:** `altura.brandmark.png` is derived from the official favicon by making the black canvas transparent. The icon is retained without the Altura wordmark; `altura.dark.svg` and `altura.light.svg` remain available as the original wordmark variants.
- **Post-processing:** `scripts/logos/post-process-logo.py` was run with the extracted brandmark to create transparent 256×256 `generic.png`, `light.png`, and `dark.png` outputs.

The favicon is the official compact mark and is suitable for the small-screen curator logo slot. No separate public brand-kit download was found; the website favicon is the canonical icon source.
