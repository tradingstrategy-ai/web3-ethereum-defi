# Nova Markets logo source

## Source

- **Homepage**: <https://nova.markets/>
- **Logo location**: The inline SVG brand mark in the official homepage loader and navigation.
- **Downloaded**: 2026-08-21

## Files

- `nova-markets.light.svg` — original vector brand mark extracted without
  conversion from the homepage. It has a `44 × 33` declared viewport and a
  `325 × 240` `viewBox`; its `#F3F3F3` fill is intended for a dark background.

No official brand kit, standalone logo file, or dark-background counterpart
was linked from the homepage.
