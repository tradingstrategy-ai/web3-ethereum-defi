# CMS Asset Management logo assets

## Sources

- **Official CMS Asset Management profile:** <https://www.cmschina.com.hk/en/AM/Profile>
- **Official CMS lock-up:** <https://www.cmschina.com.hk/en/images/CMSLogo.png>
- **Official favicon/brandmark:** <https://www.cmschina.com.hk/en/images/favicon.png>
- **Downloaded:** 2026-07-30

The CMS website's official 496×56 `CMSLogo.png` contains the compact red and
gold CMS emblem between the Latin and Chinese wordmarks. The emblem was
cropped to `cms-asset-management-hk.brandmark.png` (source rectangle x=148,
y=0, width=50, height=56) so the vault artwork uses a brandmark rather than a
wordmark. The 16×16 favicon is retained as
`cms-asset-management-hk.brandmark-favicon.png` as an independent official
reference.

The previous `cms-asset-management-hk.generic.svg` is an Asseto-provided
wordmark retained for provenance, but is no longer used as the processed
source.

## Processing

`cms-asset-management-hk.brandmark.png` was processed with
`scripts/logos/post-process-logo.py` to produce transparent 256×256 PNGs in
`eth_defi/data/vaults/formatted_logos/cms-asset-management-hk/`:

- `generic.png`
- `light.png`
- `dark.png`
