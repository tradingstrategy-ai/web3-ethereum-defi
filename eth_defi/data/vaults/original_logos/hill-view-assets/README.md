# Hill View Assets logo sources

The logo was extracted from the official [Hill View Assets website](https://hillviewassets.com/).
The homepage uses `image.jpg` as its `Hill View Assets Logo` image:

- Source page: https://hillviewassets.com/
- Source asset: https://hillviewassets.com/image.jpg
- Saved asset: `hill-view-assets.light.png`
- Format: PNG with transparent background, 1200 x 1200 pixels
- Variant: light (white Hill View mark for dark or transparent backgrounds)

The site's 48 x 48 favicon (`https://hillviewassets.com/favicon.ico`) is also
kept as a low-resolution fallback source.
