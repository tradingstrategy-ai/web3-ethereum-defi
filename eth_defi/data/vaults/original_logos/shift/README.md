# Shift logo source

The original generic logo is downloaded from the [Shift Protocol entry in
DefiLlama](https://defillama.com/protocol/tvl/shift-protocol), accessed through
DefiLlama's public icon endpoint on 2026-07-27.

The official Shift website returned HTTP 403 to automated retrieval. The icon
is used as a fallback because it is the protocol image attached to DefiLlama's
Shift Protocol listing. It is a 200 × 200 WEBP brand mark. `light.png` and
`dark.png` were generated from it using `scripts/logos/post-process-logo.py`.
