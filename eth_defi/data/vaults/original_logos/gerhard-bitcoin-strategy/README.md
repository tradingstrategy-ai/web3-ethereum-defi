## Brandmark check

The official site exposes the same text-only identity in `logo.png`, `logo@2x.png`,
`favicon.png`, and `og/default.png`; none contains an icon-only brandmark. The
linked public Telegram avatar (<https://t.me/bitcoinstrategychannel>) also uses
the full `Bitcoin Strategy Public Chat` wordmark. The X profile avatar is a
portrait of the founder rather than a project mark. No official brand kit or
icon-only asset could therefore be found to replace this wordmark without
inventing a logo. The existing processed files are intentionally left
unchanged and this project remains unresolved for the compact-brandmark audit.
