# Techemy Capital logo sources

The generic logo is the official Techemy Capital portfolio logo published by
the Techemy Group website:

- [Techemy Group portfolio](https://techemy.co/), where Techemy Capital is
  identified as the group's investment and proprietary trading arm
- [Techemy Capital logo SVG](https://techemy.co/wp-content/uploads/2022/07/portfolio-techemy-capital-logo.svg)

The light logo is the official negative Techemy Group wordmark published in
the same website footer. It is retained as a light-background variant because
the Techemy Group page identifies Techemy Capital as a group company, but it
does not include the ``Capital`` wordmark:

- [Techemy Group negative logo SVG](https://techemy.co/wp-content/uploads/2022/07/Techemy-Logo-Neg.svg)

Both files are original SVG downloads and have not been edited. The
standardised PNGs are generated with
``scripts/logos/post-process-logo.py``.
