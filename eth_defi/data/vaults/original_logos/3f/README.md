# 3F logo sources

- **Generic SVG mark**: downloaded from the official [3F brand kit](https://3f.xyz/brand/).
  - Source asset: `https://3f.xyz/brand/3f-logo.svg`
  - Saved as `3f.generic.svg`.
  - Square, dark `#020511` mark on a transparent background.
- **Light SVG mark**: downloaded from the official [3F brand kit](https://3f.xyz/brand/).
  - Source asset: `https://3f.xyz/brand/3f-logo-white.svg`
  - Saved as `3f.light.svg`.
  - Square, white mark on a transparent background.

The brand kit describes these as the official 3F mark variants for light and dark surfaces.

Post-processing generated `formatted_logos/3f/generic.png` and
`formatted_logos/3f/light.png`, each a 256×256 transparent PNG.
