# Wellington Management logo sources

- Official Wellington Management homepage: https://www.wellington.com/en
- Official SVG wordmark referenced by the homepage header (retained as a source reference only): https://www.wellington.com/content/dam/wellington/global/icons/logo.svg
- Official Wellington favicon: https://www.wellington.com/etc.clientlibs/onewellington/clientlibs/clientlib-site/resources/images/favicon.png

The curator index previously used the full Wellington Management wordmark, which is not legible in a small square. The official 32 × 32 favicon is the compact Wellington ``W`` brandmark and is saved as `wellington-management.favicon.png`. Because the favicon includes a blue/cyan square background, `wellington-management.brandmark.png` is a transparent, high-resolution derivative that retains only the white ``W`` pixels. It was then passed through `scripts/logos/post-process-logo.py` to produce the 256 × 256 `generic.png`, `light.png`, and `dark.png` outputs. The full SVG wordmark remains available as `wellington-management.generic.svg` for provenance but is not used for the formatted icon.

Source checked: 2026-07-30.
